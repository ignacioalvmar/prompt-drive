Agent interaction state

        

          
—

          

            
            
            
            
            
            
            
            
          

          

            

          
Calls feedback.agent(state, detail); the detail fields are optional. Each state is a
            distinct color and motion on the console strip: listening = cyan breathing bars, thinking = amber sweep,
            speaking = white fast bars, confirm = amber blink, action = green check, error = red cross (the last two fade
            back on their own). Every change is published as an agentState event and in the
            telemetry agent field. Demo turn plays listening → thinking → speaking → action → idle.

        

      

      

        
Push to talk (voice agent)

        

          
idle

          

            
            
            
          

          
Opens and closes the talk window without the wheel (source: 'api'). Bind a wheel button
            and choose hold/toggle on the Dynamic → Steering wheel card. The sim captures no audio: your agent
            listens for pushToTalk events and opens its microphone.

            Turning the layer off hides every feature overlay (persisted in the sim's localStorage).
